# fts_hwp
analysis scripts and notebooks for using FTS passbands to get the HWP phase shift with respect to frequency

1. data - stored FTS interferograms and HWP phase angle data. This is generated in the notebook.
2. passband-analysis -- this is a version of Tommy's bandpass analysis scripts with some changes I made. (link to Tommy's original code: https://github.com/tdalford/passband-analysis/tree/master)
3. notebooks - 260415_coord_rotations.ipynb notebook calculates the phase angles from the HWP as a function of frequency

Some of the files are kind of messy so please message me if there is any confusion.
